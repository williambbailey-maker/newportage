# Newportage

Newport Jazz Fest trip planner. React + Vite PWA. Saves locally on your device (localStorage) — no login, no backend.

Plan a 4–5 day trip around the Newport Jazz Festival: daily itinerary, festival lineup (star your must-see sets and they land on the right day automatically), and a seeded list of Newport, RI beaches, mansions, restaurants, and things to do.

## Run locally
```
npm install
npm run dev
```

## Deploy
Push to GitHub, import the repo on Vercel. Vite is auto-detected. Done.

Add to iPhone: open the Vercel URL in Safari → Share → Add to Home Screen.
